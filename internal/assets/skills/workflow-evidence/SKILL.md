# Workflow Pack — Evidence

## Objective

Guide evidence collection toward reproducible, reviewable, and well-organized proof that supports every reported finding.

## Checklist

- Capture commands, requests, responses, screenshots, logs, and timestamps as the work happens.
- Label artifacts so another reviewer can tie them back to the claim quickly.
- Preserve enough context to replay the finding without guessing hidden steps.

## Outputs

- Evidence set grouped by finding or phase.
- Reproduction notes with assumptions and environment details.
- Traceability map from raw artifact to final report claim.

## Guardrails

- Avoid storing secrets or sensitive data in unsafe locations.
- Do not rely on memory when evidence can be captured directly.
- Keep chain-of-custody and artifact integrity in mind.

## Evidence

- Raw commands, logs, captures, screenshots, timestamps, and environment notes.
- File naming or indexing scheme that supports later reporting.
